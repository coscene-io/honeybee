# Segmentation mask fixtures

`masks.json` and `codec.json` are generated by `generate.py` and checked in, so tests need no
Python. The script is deterministic: running it again must leave both files unchanged.

Regenerate them only after changing the shapes in the script. It needs Python 3.10 or newer:

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install numpy pycocotools opencv-python-headless
python packages/studio-base/src/semanticSegmentation/testing/fixtures/generate.py
```

- `masks.json`: shapes drawn on a 1280x720 frame, their COCO compressed RLE from pycocotools, and
  the OpenCV reference polygon conversion with its round-trip IoU. Tests hold the TypeScript
  conversion to at least that IoU, and use the shapes as mock mask observations.
- `codec.json`: small random masks with their pycocotools counts, for byte-exact codec tests.
  Pixels are column-major, one `"0"`/`"1"` string per column.
