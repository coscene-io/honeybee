# 分割编辑器的几何模型

契约（cosceneapis #866）规定每个观测（一个实例在一帧上）恰好有一种几何：`oneof geometry { Polygons polygons; Mask mask; }`。编辑器照搬这一点，并把「mask 是无损的一侧」作为默认取舍。

## 数据模型

`FrameInstance = { frameId, instanceId } & ({ kind: "polygons", polygons } | { kind: "mask", mask })`（`types.ts`）。

- 类型上写不出「两种都有」。读几何用 `polygonsOf()` / `maskOf()`（`maskGeometry.ts`）：mask 观测的多边形是空列表，反之亦然。
- 文档里的观测总有前景：多边形观测至少一个完整多边形（≥ 3 个顶点），mask 至少一个前景像素。删掉最后一个多边形、或橡皮擦光 mask，观测就从文档里移除，不留空壳。`polygonObservation()` / `maskObservation()` 负责这个不变量。
- 传播结果可以是 `{ kind: "empty" }`，表示该实例在这一帧被清除。

## 创建

绘制是一次会话：store 只记 `drawing = { instanceId, frameId }` 和 `creationTool`（`polygon` / `quick`，记在应用设置 `segmentation.creationTool` 里）。草稿（顶点或 SAM 点击）只在画布里，取消不留任何东西，完成时一次性写入完整几何（`addPolygon` / `addMask`）。

| 工具        | 快捷键                | 产出                                                         |
| ----------- | --------------------- | ------------------------------------------------------------ |
| 多边形      | P                     | 逐点点击，Enter 完成                                         |
| 快速标注    | Q                     | SAM 正负点，Enter 保存 mask                                  |
| 画笔 / 橡皮 | B / E，`[` `]` 调大小 | 编辑 mask 观测（或本帧还没有观测的实例），每一笔一个撤销步骤 |

树上实例的「+」用当前工具开始绘制；绘制中按 P / Q 切换工具（丢弃另一种工具的草稿）。快速标注不可用时仍可画多边形。

## 合并与转换

- 同一实例同一帧上，只要一侧是 mask，合并结果就是 mask（`mergeObservations`）：在 mask 上画多边形、把快速标注结果并进多边形观测、把多边形移到 mask 实例上，都会把多边形栅格化后求并集。栅格化只损失亚像素精度；画布会提示表示方式变了。
- mask → 多边形只在用户明确要求时做（编辑工具条「转为多边形…」）。多边形取并集，表达不了洞和单像素细条，所以先用 `maskConversionLoss` 算出 IoU、丢失/新增像素、被填上的洞和被丢弃的细小区域；有损失时弹窗确认，无损时直接转换。撤销可恢复 mask。
- 多边形 → mask 是工具条上的「转为 mask」，之后可以用画笔修改。
- 双击 mask 进入该实例的编辑（画笔），不再隐式转成多边形。

## 保存与读回（正式服务）

- 编码前按后端规则检查，并补上后端没查的两项：mask 像素总数必须等于该 topic 的解码宽×高；多边形坐标裁剪到图像范围内。不合格就在任何写入前拒绝整次保存，并指出是哪个观测。
- 读回时解不开的观测（例如 mask 尺寸不符）不显示，记入文档的 `unreadableObservations`，画布提示「本帧有 N 个标注无法显示」。适配器保留原始 wire 数据，保存这一帧时原样回传，避免整帧快照把它删掉；用户在同一帧替换或清除该实例后才不再回传。
